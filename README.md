大二網頁設計專題：《城中異客》

本專題為大二網頁設計課程的專題作品，主要介紹電影《城中異客》，透過網頁設計呈現電影相關資訊。

專案功能特色

•  SEO 優化：設定網頁標題及描述。
•  RWD 響應式設計：支援手機、平板及電腦。
•  CSS Grid 與 Flexbox：建立網頁排版。
•  多媒體展示：加入電影圖片及影片。

Vibe Coding 指令紀錄

本專題使用 AI 輔助網頁設計與程式開發。

提示一：建立網站架構

請幫我製作一個電影專題介紹網站，使用 HTML、CSS 設計，並支援手機及電腦瀏覽。

提示二：設計首頁

請幫我製作電影專題首頁，包含電影名稱、電影介紹、主視覺圖片及導覽列。

提示三：設計響應式版面

請幫我使用 CSS Media Queries 調整網頁，讓手機及電腦都能正常顯示。

專案檔案架構

•  index.html：網站首頁
•  film.html：電影介紹
•  team.html：團隊介紹
•  css/style.css：網站樣式
•  images/：圖片資源
