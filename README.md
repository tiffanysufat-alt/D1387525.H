大二網頁設計專題：《城中異客》

本專題為大二網頁設計課程的專題作品，主要介紹電影《城中異客》，透過網頁設計呈現電影相關資訊。

專案功能特色

•  SEO 優化：設定網頁標題及描述。
•  RWD 響應式設計：支援手機、平板及電腦。
•  CSS Grid 與 Flexbox：建立網頁排版。
•  多媒體展示：加入電影圖片及影片。
